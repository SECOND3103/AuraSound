# AuraSound

AuraSound는 Android용 로컬 음악 플레이어입니다.

인터넷 스트리밍 서비스가 아니라 기기에 저장된 음악을 검색하고 재생합니다.

## 주요 기능

- 기기에 저장된 음악 검색 및 관리
- 앨범, 아티스트 및 플레이리스트 관리
- 백그라운드 음악 재생
- 미디어 알림에서 재생 제어
- 재생 대기열 관리
- 앨범 및 아티스트 이미지 편집
- 데이터 가져오기 및 내보내기

## 다운로드

설치 가능한 APK는 오른쪽의 Releases 메뉴에서 내려받을 수 있습니다.

## 설치 방법

1. Releases에서 최신 APK를 다운로드합니다.
2. Android에서 출처를 알 수 없는 앱 설치 권한을 허용합니다.
3. 다운로드한 APK를 실행하여 설치합니다.

## 주의사항

AuraSound는 로컬 음악 플레이어이며 음악 파일을 제공하지 않습니다.

AuraSound는 Spotify와 관련이 없으며 Spotify가 제작하거나 보증한 앱이 아닙니다.
